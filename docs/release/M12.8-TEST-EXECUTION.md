### Canonical E2E evidence

The new E2E executes:

`cohort assignment → enrollment → structured lesson progress → AI unavailable → practice submission → authoritative verification → retry-idempotency → evidence → competency → project artifact/revision/submission → authoritative verification → evidence → competency → learner view → instructor cohort/learner view → formative guidance`.

It then transitions the cohort to `COMPLETED` and verifies evidence/competency counts do not change.

Result in run `34698420579`: **PASS**.

### Failure-injection evidence

- canonical journey survives AI outage;

- cross-tenant submission reference is rejected at persistence boundary.

Existing authority tests additionally preserve verifier outage semantics, evidence-write retry behavior, and duplicate verification/evidence protection.
